# 上洋輔元堂賒棺局徵信錄(刊年待核;Bodleian Sinica 691) / Yang fu yuan tang she guan ju zheng xin lu [Accountability register of the Fuyuantang coffin-charity bureau]: Transcription dataset

## 摘要 / Abstract

《上洋輔元堂賒棺局徵信錄》是上海輔元堂賒棺局的慈善徵信文獻，載賒棺章程、捐輸、收支與棺木經辦紀錄，可供清代上海慈善、殮葬救濟與慈善帳簿研究。本資料依Bodleian Libraries藏Sinica 691，提供108幅影像的AI輔助轉錄，包括104個編號書面與4幅封面／內封，以JSON、TXT、TEI及逐頁閱讀文字保留來源定位、疑讀和未知字數缺區。封面題簽1849與書目1837不合，且同一館目XML另記1849，確切刊印年和葉數仍待核；本版未完成人類雙校。

Shangyang Fuyuantang Sheguan Bureau Zhengxinlu is an accountability register of a Shanghai coffin-charity bureau, recording rules, donations, receipts, expenditure and coffin-related business. It supports research on Qing Shanghai charity, burial relief and charitable accounts. Using Bodleian Libraries Sinica 691, this dataset provides an AI-assisted transcription of 108 images, comprising 104 numbered surfaces and four cover or inside-cover images, in JSON, TXT, TEI and page-by-page reading text with source locators, uncertain readings and unknown-length gaps. The cover label’s 1849 conflicts with the catalogue’s 1837 while the same catalogue XML also records 1849; the printing year and leaf count remain unresolved, and human double collation is incomplete.

## English summary

This is an AI-assisted transcription of *Shangyang Fuyuantang Sheguan Bureau Zhengxinlu*, a historical coffin-charity accountability and account register preserved as Bodleian Libraries Sinica 691. The exact printing year is unverified. The source set contains 108 images, including 104 numbered surfaces; leaves have not been verified.

The release provides JSON, plain text and TEI XML, with 263 uncertainty records and four unresolved source regions of unknown extent. Eight later library or unestablished non-work marks are excluded explicitly. Included strings and unit order are preserved. Independent AI image reading and source adjudication have occurred, but human double collation, expert review and measured transcription accuracy have not. Detailed processing methods remain private. Scans are linked, not redistributed. See QUALITY.md and LICENSE.md before research reuse.
